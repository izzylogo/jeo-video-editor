# CapCut keyframe names

Read from CapCut 9.7's program files (videoeditor.dll, VECreator.dll, lyra_cli_client.dll) on 13 Nov 2026.
These are the `property_type` values a `common_keyframes` entry can have in `draft_content.json`.
The export uses: KFTypePositionX, KFTypePositionY, KFTypeScaleX, KFTypeRotation, KFTypeAlpha (all checked by opening an exported draft in CapCut).
Not used yet but available: KFTypeVolume (sound), KFTypeTextColor, KFTypeBackground* (text box), KFTypeBorder* (text outline), KFTypeShadow*.
